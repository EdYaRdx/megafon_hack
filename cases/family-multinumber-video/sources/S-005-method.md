# S-005 — повтор операции, проверенный пересказ

> Производная обезличенная копия видеокейса: D0001–D0003 ← R0001–R0003. Исторические hashes/receipts относятся к оригиналу; карта преобразований — export-map.json в корне дела.

URL: https://docs.stripe.com/api/idempotent_requests
Автор: Stripe. Дата публикации UNKNOWN; открыто 2026-11-21.
Проверены Idempotent requests, абзацы о повторе запросов, сохранении ответа, конфликте параметров и проверке до исполнения; строки веб-представления 16–23.

Документация показывает технический механизм узнавания повторной операции по ключу. Повтор после сетевой ошибки может возвращать сохранённый результат; гарантии зависят от версии API, периода хранения ключей и фактического начала исполнения.

Ограничение: пример API Stripe, не описание биллинга вымышленного оператора. Нельзя обещать такую гарантию в кейсе без подтверждения владельца системы и теста. Рекомендация — проверять повтор, неизвестный статус и сверку результата существующей операции, а не внедрять Stripe или новую платёжную систему.
