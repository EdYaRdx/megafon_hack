# Каталог кейсов

Для знакомства с продуктом откройте **основной видеокейс**. Для своей задачи создавайте новое дело из шаблона через [Quick Start](../docs/quickstart.md), не изменяя примеры.

## Основной видеокейс

[`family-multinumber-video/`](family-multinumber-video/README.md) — реальный запуск агента на учебном брифе: шесть альтернатив, выбор Product Owner, две стратегии, Resume и критический пересмотр экономики. Опубликованы самостоятельные производные **D0001–D0003**, соответствующие исходным R0001–R0003.

[Этапы видео и первоисточники](../docs/video-e2e.md) · [Продуктовая стратегия](family-multinumber-video/strategy-product.md) · [Коммуникационная стратегия](family-multinumber-video/strategy-communication.md) · [Решение](family-multinumber-video/decision.md) · [План проверки](family-multinumber-video/test-plan.md)

Содержательные выводы, неизвестное и история сохранены; учебный кейс не подтверждает реальный спрос или финансовый эффект. Все файлы дела, включая README и export-map, сохранены побайтово.
