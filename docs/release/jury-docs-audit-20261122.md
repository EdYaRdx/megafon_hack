## Демонстрационный проект: проверка каждого пункта

[Основной вход МегаФона](../demos/megafon.md) даёт прямые ссылки на все десять элементов: задачу/контекст/пять KPI; PDF и исходный запрос; исследование/источники/факты/гипотезы; шесть альтернатив со статус-кво и остановкой; выбор PO B и его границы; отдельную продуктовую стратегию; отдельную коммуникационную стратегию с примерами сообщений; план P0–P3; Resume и последствия Revise; видео и известные ориентиры времени. Все обязательные элементы **демонстрационного проекта** представлены существующими файлами. Это не утверждение, что реализованы все дополнительные технологии конкурса или доказан бизнес-эффект.

[Второй вход LinguaStep](../demos/linguastep.md) связывает бриф/CSV/web, пять альтернатив, расчёты, решение PO, две стратегии, план, настоящий source Resume и отдельный публичный D0001. Экспортированные байты не объявлены повторным запуском модели.

Почему не переписан case README: семейный README включён в export-map; оба README присутствуют в историческом репозиторном hash-срезе. Входные страницы находятся в docs/demos вне защищённых дел. Папки дел остаются доступны по ссылкам; их собственное первое техническое описание намеренно сохранено. Путь из README репозитория/for-jury к продуктовой истории — один клик. Отдельного замера 30–60 секунд с участием жюри не проводилось.

Фактические проверки этой правки сохраняются в [редакционном receipt](jury-docs-audit-20261122.json): сохранность исходных тел помеченных отчётов, неизменность защищённых данных, ссылки/anchors, repository checker, classify обоих дел, diff и scoped privacy. Suite не повторяется локально ради текста; новый main CI штатно запускает его после интеграции. [Последующие main runs](https://github.com/EdYaRdx/megafon_hack/actions?query=branch%3Amain).

В этой редактуре повторяется доступность внешних материалов, а не просмотр всей записи или новая проверка содержимого PDF. Права передачи, полный безопасный просмотр видео и отправка формы капитаном до 23:59 МСК остаются за владельцем. Аналитические планы не превращены в разрешение пилота.
