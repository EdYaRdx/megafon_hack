## Публикация основного репозитория

Решение владельца от 21.11.2026 допускает передачу существующего `EdYaRdx/megafon_hack`, обычные исторические пути и Git author metadata. Оно не разрешает секреты, raw sessions или новые неразрешённые персональные сведения. Аудит доступной истории не выявил подтверждённых credentials в своём scope; это не полная DLP-гарантия.

Байты учебного PDF-брифа получены владельцем непосредственно со страницы задания MGIMO AI Challenge; независимой проверки кабинета/версии и отдельной лицензии нет. Это исходник кейса, отдельный от финального PDF команды «Ромашка MISIS». Применимы условия конкурса и правообладателя. Видеокейс использует вымышленного оператора и учебные числа.

При проверке 22.11.2026 GitHub API подтверждает **PUBLIC**. [Публичный main](https://github.com/EdYaRdx/megafon_hack/tree/main), [PDF](MGIMO_FINAL_REPORT.pdf) и ссылки Drive — четыре материала из [маршрута для жюри](for-jury.md). Этот release не меняет visibility, лицензию или права и не выполняет отправку. Исторические пути/author metadata остаются в истории; [область privacy-проверки](publication-safety.md) указана отдельно.

Предыдущие списки QA gates, scopes аудита и незавершённые на тот момент планы сохранены как [исторический checklist](archive/submission-checklist-20261121.md), не как текущий план разработки.
