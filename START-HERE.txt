MGIMO Research V3 — unattended research + scoped Git publication

Prerequisites: Windows, OMP installed/authenticated, Git push permission, private repo C:\Projects\GitHub\megafon_hack, already-qualified .omp/profiles/research.yml / research-luna.yml / research-night.yml, docs/contest-brief.md with user-provided text, no secrets accessible to agent.

Unzip THIS archive to repo root. Start from ordinary PowerShell:
  cd C:\Projects\GitHub\megafon_hack
  .\start-overnight-product-research-v3.cmd

Research agent has read-only tools and cannot run arbitrary shell/git. CMD captures its final answer to research/product/overnight-research-v3.md and, only on OMP exit code 0 plus minimal report checks, commits only that report, the prompt, and docs/contest-brief.md. The remote push creates a review branch research/overnight-v3-20261111; it does NOT push to main. A successful process is not a quality certification. Review research, sources, and branch in morning before merge. No raw logs or model sessions are pushed. If existing report or staged files exist, launcher fails safely to avoid overwrites/mixed commits.

The report can be incomplete even when OMP exits 0: this is a research draft, not an accepted decision.
